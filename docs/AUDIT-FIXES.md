# Аудит и исправления FarchiOs

Дата: 2026-11-23

## Исправлено

- Проверка пакетов больше не выполняет `pacman -Sy` в базе установленной системы.
  Валидация использует отдельную временную базу pacman и завершается ошибкой,
  если хотя бы один пакет отсутствует.
- `make validate` использует тот же путь проверки, что и сборщик.
- Сборщик больше не пытается автоматически устанавливать `archiso` через частичную
  синхронизацию баз. Если пакет отсутствует, он сообщает безопасную команду установки.
- `farchios install` формирует профиль Archinstall с Plasma, PipeWire, multilib,
  пакетами FarchiOs и `custom_commands`, которые копируют фирменные файлы
  непосредственно в устанавливаемую систему.
- Первый запуск устанавливает GPU-драйверы и применяет настройки. Маркер
  `firstboot.done` создаётся только после успешного завершения обязательных шагов.
  При отсутствии сети настройка не объявляется успешной и может быть повторена
  после следующей загрузки.
- GPU setup поддерживает гибридные системы Intel/AMD/NVIDIA. Для современных
  NVIDIA используется `nvidia-open-dkms`; для старых поколений автоматически
  выбирается Nouveau, поскольку актуальная ветка open kernel modules их не поддерживает.
- Исправлена установка `paru`: сборка выполняется от обычного пользователя,
  установка готового пакета — с root-правами.
- Исправлены проверки драйверов и пакетов в `farchios doctor`.
- Удалены неподдерживаемые/непереносимые sysctl-параметры и глобальные переменные,
  которые принудительно включали HUD или меняли поведение всех игр.
- Исправлена активация zram через `dev-zram0.swap`.
- Установленная система больше не перезаписывает пакетный `/etc/os-release`.
- Исправлен checksum-файл GitHub Release: после склейки частей он проверяет
  `farchios.iso`, как указано в инструкции релиза.
- Исправлены команды установки `archiso` в Windows/WSL-документации.
- Выставлены executable permissions для сборочных и системных shell-скриптов.

## Что не удалось проверить здесь

В этой среде отсутствуют `pacman`, `mkarchiso`, Docker и Arch Linux. Поэтому
невозможно честно заявить, что ISO уже собрано или проверено загрузкой в QEMU.
Фактическая проверка доступности всех пакетов и сборка ISO должны выполняться
в Arch Linux или в подготовленном Docker-окружении:

```bash
make lint
make validate
sudo ./build.sh --clean
```

После сборки необходимо проверить загрузку ISO в QEMU в режимах BIOS и UEFI,
затем пройти установку на тестовый виртуальный диск и проверить первый запуск.

## Ограничения установщика

Archinstall остаётся интерактивным: пользователь самостоятельно выбирает диск,
разметку, учётную запись и пароль. Перед подтверждением разметки обязательно
проверьте выбранный накопитель — его содержимое может быть удалено.

Для старых NVIDIA-карт Nouveau может обеспечить базовую графику, но его игровая
производительность и совместимость не равны фирменному драйверу.
